## Itinerario rápido

1. Empieza por [introducción y objetivos](01-introduccion.md).
2. Recorre las [15 aplicaciones](02-usos-cotidianos.md) para identificar casos cotidianos.
3. Realiza los 15 ejercicios en orden, distribuidos en **tres bloques**.
4. Utiliza la [evaluación final](04-evaluacion-y-docencia.md) para consolidar el aprendizaje.
5. Consulta las [plantillas de prompts](05-plantillas-prompts.md) como material de apoyo.

**Nivel:** iniciación. **Duración orientativa:** tres sesiones de 60–90 minutos.

## Cómo utilizar este repositorio

- **Para docentes:** abre los archivos por bloques, demuestra cada prompt y pide al alumnado que lo mejore.
- **Para autoaprendizaje:** sigue los pasos de cada ejercicio y contrasta el resultado esperado con la respuesta obtenida.
- **Para consulta rápida:** abre [GUIA_COMPLETA.md](GUIA_COMPLETA.md) si prefieres un solo documento.

## Cómo subirlo a GitHub

1. Crea un repositorio nuevo en GitHub (por ejemplo, `guia-chatgpt-vida-cotidiana`).
2. Sube **los archivos y carpetas tal como están organizados**. Conserva los nombres y las rutas para que los enlaces funcionen.
3. GitHub mostrará automáticamente este `README.md` en la portada del repositorio.
4. No es necesario instalar ninguna herramienta adicional para leer los archivos Markdown.

## Notas de uso responsable

El contenido es educativo. ChatGPT puede equivocarse y las funciones disponibles pueden variar según la cuenta. Comprueba fechas, precios, información sensible y cualquier acción realizada en herramientas conectadas.

Los estilos `/apuntes` y `/pizarra-beltza` son convenciones explicadas en este curso, no comandos universales.
